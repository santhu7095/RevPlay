\# RevPlay 🎵



RevPlay is a Java console-based music streaming application that allows users and artists

to interact with a music library. Users can search songs, create playlists, and simulate

music playback, while artists can upload songs, create albums, and manage their profiles.



\## Features

\- User and Artist registration and login

\- Secure password handling

\- Song search and browsing

\- Playlist creation and management

\- Music playback simulation

\- Artist album and song management



\## Technologies Used

\- Java

\- MySQL

\- JDBC

\- Git
